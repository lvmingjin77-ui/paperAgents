# PaperAgents：我们一起梳理

> 目标：从明确的研究问题出发，形成高价值、可检验的 idea。
> 下文是设计底稿；标为“待调整”的部分，不代表当前代码已经实现。

## 1. 输入包含什么

主要输入是一份研究任务 Markdown，包含：

| 信息类别 | 写什么 |
| --- | --- |
| 研究问题 | 研究什么现象，想解决什么问题 |
| 目标与开放问题 | 希望改善什么，哪些原因还不确定 |
| 任务定义与评价 | 输入输出、指标、对照、什么算有效或无效 |
| 已知线索 | 相关论文、数据集、代码；是调研入口，不是指定答案 |
| 约束与资源 | 本机或服务器、算力、已有数据、使用限制 |
| 预期交付 | idea、实验、代码、证据和结论等 |

不知道的可以明确写未知，不能为填满输入而预设方法或瓶颈。
模型/API、并行数、专家数量、循环上限属于运行配置，与科研任务分开。

## 2. 输入进入系统后经历什么

研究任务
→ **scope**：拆解问题，确定检索范围与纳入标准
→ **corpus**：寻找、筛选论文，保存来源与可用全文
→ **reading**：形成论文卡，提取方法、证据、局限与思路
→ **domain**：综合不同路线、竞争解释、证据和知识缺口
→ **selection**：比较专家组合，选择核心论文及临时能力
→ **paper**：深读入选论文，补齐关键方法、实验和代码理解
→ **expert_review**：检查专家能力是否足以承担任务
→ **ideation**：专家提案、交互、修订、查新和评审
→ **experiment**：实现与审核，运行基线和候选
→ 实验结果回流，继续修订 idea

待调整：reading 与 paper 的阅读深度边界；paper 不应因非关键内容未核验就一律停止。

## 3. Agent 怎么形成

Agent 是“模型 + 角色职责 + skills + 专属知识与工具 + 当前任务上下文”。
构建专家不是重新训练模型，而是形成可复用的知识和能力资产。

| 角色 | 如何形成 | 负责什么 |
| --- | --- | --- |
| 领域专家 | 汇总论文卡、方法路线、竞争解释和证据 | 提供全景，组织议题，综合取舍 |
| 论文专家 | 选定论文后，深入拆解其方法、实验、思路和必要代码 | 提供具体方法视角，提出和修订候选 |
| 临时专家 | 针对明确缺口，提供专题材料与技能 | 补充统计、验证、工程或其他方法能力 |
| 独立核查/评审 | 独立上下文，读取待审产物及来源 | 查新、核查证据、检查方案能否有效检验 |

论文专家优先代表近期且相关的方法贡献。经典理论、数据和基线不自动占核心席位。
专家知识保存后可复用；新任务核对适用范围，只补关键缺口。
同一基础模型扮演不同角色，不等于判断天然独立，差异主要来自材料与方法视角。

## 4. Agent 怎么交互

**先独立，再交流。**

1. 各专家先独立提出候选，避免一开始就顺从别人。
2. triage 比较候选与已有工作，识别重复、部分重叠和共享问题。
3. 作者确认合并或说明区别，保留来源与版本。
4. 领域专家组织议题：哪些分歧需要谁回应，哪些属于共同前提。
5. 专家交叉质疑；作者答辩、修订或撤回；原质疑者复核，可多轮。
6. 独立查新，领域专家综合取舍，独立评审检查最终方案。

交流通过结构化产物和讨论台账传递，不是所有 agent 始终自由聊天。
每条异议指向具体候选与版本，保留依据、回应及处理结果；网页展示这些真实记录。
协调器负责派任务、存档和推进，不替专家判断科学结论。

当前领域专家也参与提案，因此综合它自己的方案时存在偏向风险，需独立评审制衡。

## 5. 最后怎么得到 idea

论文中的机制与思维策略 + 当前问题的证据与缺口
→ 专家提出竞争假设
→ 通过质疑和回应修订
→ 查明相对已有工作的增量
→ 综合选择值得检验的方案
→ 独立评审

一个可进入实验的 idea 应说清楚：

- 解决哪个问题，提出什么机制或诊断假设；
- 相对最近工作有什么价值；
- 依赖什么前提，有哪些竞争解释；
- 用什么基线、对照和观测支持或反驳它。

候选区分新机制、诊断和基线，不把常规基线包装成创新。
六维评分用于展示判断依据，不用加权总分决定赢家。
效果未知是实验要回答的事；评价无效则不能直接放行。

## 6. 不通过和实验后怎么办

| 情况 | 返回哪里 |
| --- | --- |
| 缺资料或事实依据 | 补证据，再交专家或综合复核 |
| 机制或关键前提需要改 | 作者修订，再讨论、查新和评审 |
| 只有运行才能判断 | 设计有效的判别实验，经审核后执行 |
| 缺外部资源或循环上限已到 | 暂停，明确下一步 |
| 实验完成或执行失败 | 将真实结果及限制交回专家，保留、修订或淘汰候选 |

不能保证每轮都有合格 idea，也不能把执行失败直接当成科学假设失败。
