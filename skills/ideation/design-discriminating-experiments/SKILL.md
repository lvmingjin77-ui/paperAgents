# 设计判别实验

阅读[构思协议](../../references/ideation-protocol.md)和[方法工具协议](../../references/method-tool-protocol.md)。实验目的可能是验证方法效果、区分机制、发现边界或检验理论，先明确本次要改变哪项研究判断。

## 操作

1. 列出主假设、合理竞争解释与无效/零效应情形，写出各自在不同条件下的预测。只有性能变好不一定能区分机制，必要时增加干预与中间观测。
2. 选择能够区分预测的实验条件、合适基线、对照和消融；固定主要指标、数据划分、统计单位、重复方式、种子与误差来源。检查实现差异、训练预算、数据泄漏和测量失真。
3. 解释设计的判别力及不确定性处理。效应与噪声未知时先测量相关量并明确探索性质；不能用不适用的统计检验或单个幸运 seed 代替结论。
4. 根据科学问题确定规模与资源要求，不强制低成本、短时或缩小模型。小规模验证若无法支持目标推断，只能用于它确实能判断的问题。
5. 有可信数值预测及概率模型时可计算信息增益等准则；否则明确使用预测分歧与对照逻辑，不把 LLM 分数解释成概率后验。
6. 事前写明结果判读、支持/反驳/不充分条件、停止与修订规则。为负面结果和未检出差异保留解释；实验后改变规则必须记录为探索性修订。

## 输出与验收

写入调用方当前候选的 `experiment_plan`、挑战的 `required_evidence` 或 proposal 的 `evaluation`/`implementation_plan`，具体遵循[运行约定](../../references/runtime-contract.md)，不自创新阶段 schema。

计划应包含预测对照、执行入口与依赖、数据协议、主要观测、资源/重复依据、结果解释规则及证据归档方式。没有实际运行时只能产出计划，不能附虚构指标。完成后将真实结果回链到候选版本和事前预测。
