# 学习论文的论证与呈现

输入为 [understand-paper](../understand-paper/SKILL.md) 已建立的材料、导航及科学分析。阅读[呈现分析协议](../../references/paper-communication-protocol.md)，在原文锚点上分析“如何让读者判断主张”，不重复整篇内容摘要。

## 操作

1. **建立论证结构。** 连接研究问题、缺口、核心主张、方法选择、关键证据和适用边界，说明章节及关键段落各自解决什么阅读问题。对照正文与附录，区分作者实际展示的组织和系统推断的修辞意图。
2. **检查主张与证据的距离。** 找出结论在何处首次提出、定义/假设在哪里补齐、证据何时出现、限制是否能被读者看到。分析叙事的清晰与缺陷；论文讲述顺序不等于作者发现顺序，结构流畅也不能提高证据强度。
3. **学习图表的表达选择。** 回看真实图像/表格及图注、表头、单位和脚注，分析读者要比较什么、变量如何编码、对照与不确定性怎样展示，以及呈现是否容易误导。只有文字或图注时，仅分析能核实的内容，缺失视觉内容记未知。
4. **提炼可迁移做法。** 将有来源的观察改写为“目标读者问题 → 所需证据/数据 → 组织或表达操作 → 检查标准”，保留适用条件、失败情形和替代方案。复用论证结构与设计原则，不复制原文句子、图片或视觉品牌；没有目标任务测试就保持迁移未验证。
5. **连接已有知识。** 复用同一主张、轨迹和来源标识；科学解释由理解与论证资产承载，本技能记录它们怎样被表达。若原图代码或数据存在，给真实入口及验证状态，不能因看懂图就宣称能够重绘。

## 输出与交接

按当前 `request.output_schema` 在 `knowledge.communication_analysis` 保存 `status`、`writing_structure`、`display_patterns`、`transfer_recipes` 与 `limitations`。每个观察/策略回链真实已读的 `{source_id, anchor_id}`；字段与状态见[协议](../../references/paper-communication-protocol.md)。数组可为空，但应说明没有相关内容还是材料未取得，不能填假图表凑齐格式。

交给 [verify-expert](../verify-expert/SKILL.md) 核对结构忠实性、图表观察、推断标签和迁移边界。后续写作或绘图调用这些知识时，重新核对目标研究的真实结果和数据；原论文的表达经验不是目标论文结论、显著性或图像数据的来源。
