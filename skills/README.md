# PaperAgents 技能

按知识、构思、工程、写作、评审职责分类，角色按当前任务加载技能，不按专家身份复制技能。

- 知识：scope/corpus 只找材料；reading 广度卡片；选队后深读方法、思路、代码和表达。
- 构思：独立提案、一次交叉意见与回应、去重、可检验性评估、实验后解释和进化。
- 工程：评测底座、机制实现、独立实现核对；实验由运行器执行。
- 写作评审：主张与证据驱动的章节、图表、独立评审和开发集补实验。

`registry.json` 是技能索引，`paperagents/skills.py` 定义阶段加载。字段以每次任务的 output_schema 为准；技能描述科学操作，不重复定义另一套状态机。已验收的专家知识保存在项目 library/，它是可复用材料，不是模型训练或自动部署的 MCP。
