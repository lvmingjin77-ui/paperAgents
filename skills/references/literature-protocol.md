# 系统检索与全文学习协议

目标是在明确范围内尽可能完整地学习相关工作，并使遗漏可见。不能承诺互联网上全部相关论文均已收集。

## 先固定范围

记录研究方向、任务/问题、领域词汇及同义表达、相邻机制、时间窗口、会议集合和纳入/排除标准。“近三年”默认按研究启动日向前滚动三年，记录具体日期；用户采用三个会议年度时改用该口径并注明。范围不能偷偷缩成最容易检索的几个关键词。

“顶会”需要对应领域的会议集合与选择理由，使用官方 proceedings、会议网站或可靠索引核对；不要固定为所有领域同一张榜单。正刊论文、workshop、预印本、journal extension 和补充材料分别标注。较早的奠基论文、领域外机制论文可进入补充集合，不混入近三年覆盖统计。

## 构建可审计语料

1. 先枚举目标会议、年份及公开论文目录，再结合多组主题查询筛选；目录枚举不可用时记录替代方法和盲区。
2. 查询至少覆盖问题/任务、核心机制、不同术语、负面现象或约束，并从合格种子做前后向引文扩展。记录服务覆盖、速率限制、分页/返回上限与失败，不能把截断结果算作完整目录。
3. 按稳定标识和题名/作者核对去重，用 `same_as` / `related_to` 关联预印本与会议版，各版本自成一条、保留差异。主结果引用实际学习的版本。
4. 对每个发现条目记录筛选决定与理由；不因引用量低、结果负面、没有代码或不符合当前 idea 而排除。边界案例保留待定理由。
5. 对纳入论文获取合法可访问的全文与补充材料并保存；逐篇学习（方法、推导、实验和限制）由 reading 任务完成，corpus 不精读。仅有摘要的论文保留在语料中并标记全文缺失，不伪造全文路径。
6. 将知识按问题、机制、假设、数据/评估协议、结果、失败与分歧组织，保留跨论文关联；写清研究路线如何演进以及哪些问题仍没有答案。

## 覆盖报告

覆盖报告至少能回答：计划中的会议×年份有哪些；发现、去重、纳入、排除、待定、全文已读、全文缺失分别多少；各类检索何时执行；哪些边界或术语尚未覆盖；新增查询是否仍持续发现重要论文。数量必须来自真实条目，不凭模型估计。

“已完成当前范围的检索轮次”只表示计划中的检索任务已处理。它不等于“全部文献已检索”或“全部领域知识已学会”。检索趋于稳定可以支持发布带限制的语料版本，不能抹去全文缺失、未决筛选或索引盲区。核心机制所依赖的缺失全文阻止专家对该机制宣称精通。

## 领域学习与三篇选拔的顺序

完整语料和领域地图先于三篇核心论文的选拔。三篇是常驻专家团队的注意力分配，不是领域语料的上限。选出核心论文后，领域专家仍可引用全部已学习语料；新证据可触发临时专家、重新选择或知识版本更新。
