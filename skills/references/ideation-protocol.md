# 构思、异议与实证推进

## 机制优先的候选组合

领域专家与三名论文专家先独立读取同一研究任务和固定知识版本，提交初始机制卡；独立阶段不要把其他专家的候选或 PI 偏好提前放入其上下文。可共享经核验的事实，不共享未提交观点。角色名不同不能保证观点独立；在来源、机制、假设、反例或外部知识上形成真实差异。

候选组合可覆盖机制迁移、冲突解释、现有假设失效、研究遗漏、测量/评估问题或新的理论解释。选择与问题有关的探索方式，不机械填满类别。相近变体记录同一谱系；修补措辞或加一个组件不能重复算新发现。

每个候选应能说明：解决何种具体问题；机制如何产生可测变化；原始来源是什么；新增一步是什么；必须成立的假设是什么；最接近工作已做到哪里；什么观测会反驳它；如何判别竞争解释。

## 讨论协议

讨论顺序是：独立提案（密封）→ 重叠初筛 → 领域专家列议题 → 交叉质疑（编号异议）→ 作者逐条答辩 → 原质疑者独立复核 →（仍有未解阻塞异议时回到答辩，直到轮数上限）→ 深度查新 → 综合 → 独立评审。协调器自动推进这些轮次；每一轮的异议、答辩和复核在本轮结束后统一写入 `runs/<id>/debate/ledger.md`，复核时只给质疑者看自己的异议，以减少附和。答辩中改变科学核心或组合候选会生成新 `idea_id` 并保留 `parent_ids`，新候选在复核阶段接受质疑。综合选择 `ready` 的候选不能残留未关闭的阻塞异议；不论综合结论如何，都由独立评审复核。

以下为历史运行（v2）的说明：

当前调度顺序是独立候选、一轮交叉挑战、查新、综合、独立提案审查。挑战围绕可审查的主张，记录提出者、依据、反例与影响；批评者解释异议成立的条件。程序没有自动的作者答辩、交换后再评或候选修复阶段，不能凭空补写响应、已完成的修订或共识。只有后续真实记录才能支持这些陈述。

需要作者修订、撤回或再讨论时，协调器显式退回相关阶段，保留旧候选并向新任务提供异议与版本。实质改变机制、核心假设或关键前提的组合是待审查的新候选，不能沿用旧 `idea_id` 的查新结论直接晋级；当前综合任务应输出 `needs_evidence`，列明需重做的候选、挑战和查新工作。保留少数意见，不能将语气、身份、票数、Elo、审稿分或强制共识当作证据。

退回后，假设任务有本专家历史候选时，通过 `revision_context` 接收真实产物回执及相应挑战/查新，按[修订协议](hypothesis-revision-protocol.md)回应。没有对应历史时仍按初始生成处理，不凭空制造作者答辩；新候选重新走下游审查。本机实验协调器自动登记实际搜索结果并返回 `hypothesis`；外部实验通过 `feedback` 登记后显式 `revise`。这不等于已经实现实验前自由决定议程的多轮辩论。

把逻辑矛盾、与来源不符、已知重叠和等待实验的问题区分开。前三者可能通过补材料、修订或拒绝解决；等待实验的分歧应生成可区分预测。实验前不能仅凭讨论宣布事实问题已解决。

## 实验设计

优先选择能够改变研究判断的实验，而不是仅让结果看起来更好。对候选及竞争解释写出预测、主要指标、数据/划分、对照、消融、统计单位、重复/种子、效应量与不确定性、停止/修订条件。区分探索性分析与确认性分析。

在可明确数值预测及概率模型时，可以使用预期信息增益或其他实验设计准则；其不确定性只针对已定义模型集合。没有可靠似然时，以预测差异和可判别性进行设计，不把 LLM 自信分数叫作后验。性能优化与区分科学解释可以需要不同实验。

规模由检验能力与质量需要决定，不强制先跑便宜实验。若一个小规模实验不能区分解释、检测预期效应或反映目标场景，扩大设计或明确结果不充分。负面结果、无显著差异、测量失效和功效不足分别解释。

## 产物与回流

源论文事实、系统推断、预期结果和真实观测分开保存。实验回流时关联候选、版本、预先预测与运行证据，说明其支持、反驳或未能区分哪些主张。更新后代假设和知识包时保留谱系与不确定性；不要静默把事后解释改成事前预测。

维护保留、修订和拒绝方案及理由。不同机制、仍有信息价值的候选可作为 alternatives 留存；不足以支持主问题的候选不能靠“多样”获得科学资格。`ready` 只表示 proposal 足以交给实验阶段，不表示假设已被证实或论文可发表。

## 方法来源与适用边界

本协议借鉴以下机制而不承诺复制其论文结果：

- [IDEAgent v2](https://arxiv.org/html/2607.22375v2)：机制卡、谱系、修复和多样性组合。开放题评价主要依赖模型；算法任务的可执行验证不能推广到任意科研问题。
- [Heuresis v2](https://arxiv.org/html/2606.25198v2)：保持独立探索分支及交换时机。其 ML 实验也表明多样性、新颖性和有效性能并非同一目标。
- [MOOSE-Chem](https://arxiv.org/html/2410.07076v5)：背景与启发来源分开、组合多个机制。其主要证据是回溯重发现，不是任意跨领域迁移的保证。
- [Bayesian Model Discovery](https://arxiv.org/html/2610.25747v1)：竞争解释、数值反馈和信息驱动实验。其验证限于模拟任务及可表达的模型族。
- [科研 ideation 人类评估](https://arxiv.org/abs/2409.04109)：新颖性、可行性和最终研究产出分别评价；盲评不能替代实证结果。
- [多 agent 辩论受控研究](https://arxiv.org/html/2511.07784v1)：保留独立纠错与有效论证。将逻辑谜题证据用于科研协作是一项设计推断，需要在本系统中验证。
